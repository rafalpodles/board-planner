# Security policy

To report a vulnerability in Board Planner (the self-hosted image, the worker, the macOS menu bar
app or the hosted service), write to **contact@board-planner.com** with a subject that starts with
`SECURITY:`. You can also use GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability), where it is enabled.

Please do not open a public issue or pull request for a vulnerability.

What we commit to, and the rest of the policy — response times, fix targets, coordinated
disclosure, safe harbour, scope and supported versions — is in the full policy:
<https://board-planner.com/legal/security/>.

Advisories for fixed vulnerabilities are published on this repository's Security tab.
